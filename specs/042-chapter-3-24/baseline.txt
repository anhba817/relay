— thirty-one `FOREIGN` pairs and a docstring naming the wrong chapter — and its `gaps.md` item
C8 predicted the class would keep recurring. This one is `check-refs.py`'s citation rule:

    cited = re.escape(ident) + r" \(3\.23\)"

hard-coded, and missed by a `sed` that re-pointed every other mention of 3.23. On its first run
it reported **all twenty-four requirements and all six criteria as "cited by no task at all"** —

**A checker that cries wolf on a healthy tree is how a real problem hides**, and thirty-four
false ones would have buried the three real ones underneath. It now derives the chapter number
from its own directory name — `042-chapter-3-24` -> `3.24` — so the next copy cannot inherit it.
