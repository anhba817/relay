        services/api/src/internal/backfill.controller.ts:123   resume

      The other three pass 2 named do not error, and the reason is the finding:
      :255 builds a `Message` for `fanout.publish`, so it is type-checked; :270
      builds the HTTP RESPONSE BODY, whose type is the controller's own and is
      inferred. **:270 is a door and the compiler is silent about it.**
      And the gateway is clean at 0 errors — `session.ts:1628` forwards

      wrong about that site too.

      `Message`, not doors. It is necessary and not sufficient for T019, and a
      third hand list — this time mine, in pass 2 — was wrong in both directions
      again. The derivation has to ask which handlers RETURN a message-shaped
      body, whatever type annotates it.

      already returns `{requestId, environmentId}` with the `?? "unknown"`
