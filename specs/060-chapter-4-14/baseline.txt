T047  THE ARM THAT TURNED NOTHING RED, AND WHICH KIND IT IS
      The `ready`/`rejected` guard is **unreachable at runtime and load-bearing
      at compile time**. `announce` runs only when the compare-and-set applied,
      and one that applied set the state to the verdict — so the guard cannot
      fire. It stays because `state` arrives typed `string | null` and this is
      what narrows it; deleting it needs a cast, and a cast is a claim the
      compiler stops checking.

      4.11 found an early return that was an optimisation wearing a branch's
      clothes. **This is the other kind — a type narrowing wearing a runtime
      guard's clothes.** Said out loud in the file, so its coverage is not read
      later as a gap.
