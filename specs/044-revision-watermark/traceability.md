## 3. What the analysis passes changed here

**This file did not exist until implementation began**, and its absence was found by copying
feature 043's instruments rather than by any of the three analysis passes. `regen-traceability`
failed with `FileNotFoundError` on its first run — the loudest possible way to report a missing
artifact, and it took an instrument to ask.

**The six instruments arrived stale, which is gaps item C8 being paid again.** Feature 043's
ledger records that class: they are copied per feature, carry the predecessor's configuration,
and have no owner. On their first run against this feature they reported problems in every
document — and **five were real defects that three analysis passes had missed**:

| What the instruments found | Passes 1–3 |
|---|---|
| `traceability.md` absent entirely | missed |
| three tasks naming no file path | missed — a looser check said all 35 had one |
| task ids cited in `plan.md` and the checklist | missed |
| success criteria named only in scenario headings, not in the `**Expected**` lines a person runs | missed |
| the checklist not recording the count it certifies | missed |

contained a backticked token and got 35 of 35; `check-refs.py` asks whether it names a path or a

and names nothing to a reader who arrives at that line first.
