T004 — THE GREEN BASELINE: FOURTEEN GATES, ALL ZERO
----------------------------------------------------

    platform   typecheck 0 · lint 0 · build 0
    tutorial   check:fences 0 · check:docs 0 · check:figures 0 · check:srs 0 · check:errors 0
    feature    check-refs 0 · sweep 0 · check-prose 0 · check-quickstart 0 ·
               check-checklist 0 · regen-traceability 0

Exit codes written to a file, never accumulated in a shell variable: `fail=1` inside a
`for … | sort` pipeline runs in a subshell and dies with it, and this repository has printed
"ALL GATES: GREEN" over a red one that way.

**THE FIRST RUN FOUND EIGHT GATES, NOT FOURTEEN.** The six instruments in this directory did
not exist — `tasks.md` named fourteen because feature 043 had fourteen. They were copied from
043 and re-pointed, which is gaps item C8 being paid for the seventh time: per-feature
instruments with no owner, copied forward, carrying the predecessor's configuration.

**AND THEY FOUND FIVE DEFECTS THAT THREE ANALYSIS PASSES MISSED.**

    traceability.md absent entirely            regen-traceability, FileNotFoundError
    three tasks naming no file path            check-refs
    task ids cited in plan.md and the checklist check-refs
    criteria named only in scenario headings   check-quickstart
    the checklist not recording its own count   check-checklist
    the plan naming no phases against six       sweep

**The third one is the instructive one.** An earlier hand-rolled validation asked whether each
task line contained a backticked token and reported 35 of 35 clean. `check-refs.py` asks
whether it names a path or a command, and found three that do not — `T008` said "in the same
file", which reads fine when following along and names nothing to a reader who arrives at that
line first. **A looser check that agrees with you is worth less than a stricter one that does
not.**

Two instrument changes were made rather than suppressed:

  - `check-refs.py` now understands `SRS FR-016a` as another document's clause. This feature is
    built on two SRS clauses and cites them throughout; without it every citation reported as an
    undeclared requirement. The prefix is required rather than optional — a bare `FR-016a` is
    still a defect, because this spec's own numbering reaches FR-015 and the next id collides.
  - `plan.md` gained a Phases section. `sweep.py` compared plan against tasks and found six
    phases against zero; a plan that leaves its reader to derive the shape from the task list is
    one the task list cannot be checked against.
