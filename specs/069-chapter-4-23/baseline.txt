AND ONE THING THIS MILESTONE MUST NOT ASSERT
--------------------------------------------------------------------------------
**JOURNEY 3 STAGE 5 REACHES THE REAL-TIME SURFACE AND IT STILL CARRIES UUIDS.**
`docs/03` Stage 5: *"connected clients see the deletion event immediately
(FR-RTM-05)"*. Every gateway frame carries `channel: <uuid>`, the session
response hands a connecting client a list of channel uuids, and a socket send
goes to a door typed `z.string().uuid()`.

So a script asserting **"the order number alone, end to end"** fails at the
socket, for a reason 4.22 deliberately did not fix (`gaps.md` 068-1). SC-007 in
068 names **Stage 2** for exactly this reason. **This milestone must either
scope its script to REST or assert the uuid at Stage 5 on purpose** — and the
second is the better chapter, because the gap is real and publishing it is worth
more than hiding it.

AND TWO THINGS THAT WILL COST YOU A RUN IF NOBODY SAYS THEM
--------------------------------------------------------------------------------
**An application credential may send only as a BOT.** `sender_not_permitted`.
It cost 068 four runs across fixtures and sweeps.

**The sealed suite and the api lane want opposite machine states.** The sealed
suite needs the composed services UP; the api lane needs them DOWN, or a second
relay drains rows its tests are counting. `turbo run test:integration` with
`--concurrency=1` stops at the first failure, so one command cannot satisfy both
(`gaps.md` 068-9).
