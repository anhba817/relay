actual count is **nineteen**, and the four extra are worth naming because
budget-versus-actual is the point of having budgeted at all:

  +2  messages.service.ts, internal.controller.ts
      The event envelope carries the sender's EXTERNAL id, and threading it from
      the caller beat looking it up inside the write transaction — a query every
      message would pay forever. R11 did not foresee the event needing it.

      A build-order dependency the gateway's 3.2 socket suite always needed and
      never declared. Exposed by this chapter, fixed forward.

      3.1's global organisation count, fragile under concurrency, removed.
      Exposed by this chapter's crash tests, fixed forward.

own work. The budget was right about the shape of the change and wrong about how
much of Part 3's past this chapter would end up touching.
