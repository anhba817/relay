## Phase 5: A virus is rejected, by a scanner that is running (US3)

**Goal**: FR-MED-04's scan, and FR-009's refusal to guess when the scanner is down.

- [X] T037 [US3] Add ClamAV to `compose.yaml` — **151 MB compressed, 7 layers** (`research.md` R5) — with `INFRA_SERVICES` updated in the same commit (T018's rule). **IN THE DEFAULT PROFILE, WHICH IS THE OPPOSITE ANSWER FROM THE WORKER'S** (T018).   **THE WINDOW IS MEASURED, NOT HYPOTHETICAL** (analysis pass 8). A container started from a cached image answered, ten seconds in, `ClamAV 1.5.4/28122/Sun Sep 13 06:26:25 2026` — **the baked copy, thirteen days old** — and read `28135/Sat Sep 26` by twenty seconds. - [X] T038a [US3] **Run T038's check red inside the startup window, which needs no contrivance.** Start the container and ask before freshclam finishes; the check must refuse. ## Implementation Strategy

**MVP is phases 2 through 5**, for the reason above: `ready` has to mean scanned.

**What this chapter could get wrong, ranked by how quietly it would happen:**

1. **A bucketless store, which makes the whole worker inert and says nothing.** Every `HEAD`
   answers 404, the sweep reads every one as "not uploaded yet", no test fails, and the only
   symptom is objects staying `pending` — which is what an un-uploaded object looks like.
   **Quieter than anything else on this list**, and a condition this platform has already met
   once. T021a, T021b.
2. **Verifying the client's claim twice and calling the second one a verification.** The store
   echoes back whatever `Content-Type` the client PUT with, so a worker that reads the response
   header has learned nothing and will pass every test somebody thinks to write. **T035 is the
   test that catches it** and it is in US2 rather than US1 on purpose.
3. **A scanner with no definitions.** Reports clean on everything, answers its socket, passes a
   health check that asks whether the socket answers. T038.
4. **Marking an object `rejected` because the scanner was down.** Deletes a customer's photo to
   record an outage. T041, and the test has to prove the pause was a pause by letting the
   scanner come back.
5. **A dimension reader that is right for PNG and silent for WebP.** One format per test. T024.
