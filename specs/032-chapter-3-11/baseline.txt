## T004 — three consecutive integration runs

  run 1  exit 0  190s  256 tests
  run 2  exit 0  189s  256 tests
  run 3  exit 0  188s  256 tests

Green three times, same count, 2s of spread. T005 had nothing to fix forward.

**A defect was found here, and not by any of the seven analysis passes.** The
quickstart's V12 battery extracts the test count from the lane's output, and the
command could not have worked: it anchored on `^\s*Tests `, and in a turbo log
every line carries a `@relay/<pkg>:test:integration:` prefix. Measured:
`grep -E '^\s*Tests ' itest-1.log` returns **0 lines**. It also took `tail -1`
where a run prints **five** summary lines, one per package — and `@relay/e2e` is
the package a `[a-z-]+` pattern silently drops, because of the digit. The first
version of the same command, which the fourth analysis pass replaced, was wrong
differently: it read the failure count as the total on red runs. Fixed against a
real log and recorded in the quickstart, both wrong versions included.

## Phase 3 — the credential

Green: lint, build, typecheck, unit 333, integration **271** (from 256; +9
`config.itest.ts`, +6 `credentials.itest.ts`), 190s.

**`PLATFORM_CREDENTIAL_ENV` had no consumer outside its own file** — M16's grep,
run and recorded rather than guessed. The export survives as the dispatcher's
variable name and gains a sibling, `GATEWAY_CREDENTIAL_ENV`.

**The env read stays at call time**, which M16 flagged as the refactor's quiet
risk. `credentials.itest.ts` SETS both variables during the test and says so in a
comment; a module-level map of resolved secrets would have gone green against a
credential nobody configured.

**`ApiClient` grew a method and seven stubs stopped compiling** — six inline
literals in `resume.itest.ts` and one factory in `session.test.ts`. The six became
one edit: `boot(api: Omit<ApiClient, "reportUsage">)`, with the method supplied
inside. The `Omit` says which half of the client those tests speak to, which is
more honest than six copies of a no-op.

**Compose default is 38 characters**, checked, because `resolvePlatformCredential`
refuses anything under 32 and a short default would have made the gateway
unauthenticated in every local run while looking configured.

**One lint failure**: `internalUsageReportRequestSchema` imported and unused —
the request is validated by the api, not by the caller that builds it. Removed.
